My own website serving as portfolio and self-expression.

Background

After thinking about what I want to do after university, I came to the conclusion that I need to practice coding and building projects for my portfolio. While searching through the internet for ideas, I found the idea of making a website that itself is the portfolio.

Goal

I wanted to create a website which not only serves me as a portfolio to present my skills and advancements over the years but also as a way of expressing myself to the internet and potential companies I want to apply to. To achieve this goal I divided this project into phases to help me going step by step.

Development

Phase 0: Fundamentals IN PROGRESS

Building the base of my website using only raw HTML, CSS and JavaScript. Only building a projects page, about page and a contact page.

Phase 1: Tooling and TypeScript

Migrating from the raw basic website to a npm with vite setup. This step is for learning to work with TypeScript.

Phase 2: React

Migrating to React as last migration step. React is probably the most used modern framework, learning to work with it maybe very crucial.

Tech Stack

Learning

What I learned so far:

Working with Web Components for the header and footer, keeping CSS consistent through design tokens, structuring long term migration plan instead of rewriting everything at once
